# Учебная платформа — Преподавание дисциплин онлайн и оффлайн

Интерактивное веб-приложение учебной платформы, разработанное на основе макета Figma в рамках лабораторной работы по разработке пользовательских интерфейсов.

Платформа предоставляет онлайн/оффлайн образовательные услуги физическим и юридическим лицам по широкому спектру фундаментальных и прикладных дисциплин.

---

## 🎯 Выполненные цели и задачи

### 1. Архитектура приложения на стандартном React
* **Строго без сторонних UI-библиотек**: компоненты, состояние, модальные окна, фильтрация, аккордеон и навигация реализованы на чистом React (хуки `useState`, `useEffect`, `useMemo`, функциональные компоненты) и чистом CSS.
* Модульная и масштабируемая структура каталогов:
  ```
  src/
  ├── components/
  │   ├── Header/          # Навигация, логотип, переключатель облака, мобильное меню
  │   ├── Hero/            # Главный баннер (текст из макета), кнопка «НАЙТИ ЛЕКТОРА», статистика
  │   ├── About/           # Секция о платформе (текст из макета) и ключевые форматы
  │   ├── Partners/        # Партнеры (ICL, Татнефть, VK, Сбер, МФТИ, ВШЭ) с описанием кейсов
  │   ├── Lecturers/       # Каталог лекторов, фильтры, карточки, детальная программа 10 лекций
  │   ├── BookingModal/    # Интерактивная форма записи и бронирования с валидацией
  │   ├── Calculator/      # Калькулятор стоимости обучения со скидками за объем
  │   ├── HowItWorks/      # 4 шага организации образовательного процесса
  │   ├── Reviews/         # Отзывы студентов и корпоративных заказчиков
  │   ├── FAQ/             # Интерактивный аккордеон ответов на частые вопросы
  │   ├── Contact/         # Контактная информация и форма запроса КП для юр. лиц
  │   └── Footer/          # Подвал платформы со ссылками и копирайтом
  ├── data/
  │   ├── lecturersData.js # 10 преподавателей, 30 дисциплин, 300 тем, тарифы, степени
  │   ├── partnersData.js  # Данные о партнерах
  │   └── siteExtraData.js # Статистика, отзывы, вопросы, этапы работы
  ├── styles/
  │   └── index.css        # Глобальные CSS переменные, типографика, адаптивность
  ├── App.jsx              # Корневой компонент с управлением экранами и модальными окнами
  └── main.jsx             # Точка входа приложения
  ```

### 2. Точное соответствие макету Figma
* Заголовок и главный призыв:
  > *"Наши лекторы — признанные специалисты в своих областях, готовые делиться опытом и знаниями."*
  > Кнопка: **«НАЙТИ ЛЕКТОРА»**
* Текст блока «О платформе»:
  > *"Наша учебная платформа соединяет компании, образовательные учреждения и НКО с профессиональными лекторами, спикерами и тренерами. Мы упрощаем процесс подбора, бронирования и организации лекций, помогая находить экспертов, которые не просто делятся знаниями, но и вдохновляют аудиторию."*
* Блок партнеров:
  * **ICL** — описание деятельности и совместных тренингов.
  * **Татнефть** — описание сотрудничества в корпоративном обучении.
  * **VK, Сбер, МФТИ, ВШЭ** — дополнительные академические и отраслевые партнеры.
* Свойства и структура компонентов карточки лектора:
  * Место для фото преподавателя (с поддержкой облачной загрузки)
  * ФИО, учёная степень, образование (вуз, факультет, год), стаж
  * Преподаваемые дисциплины с подробным описанием
  * Стоимость и тарифы (разовое занятие, пакет из 8 занятий, интенсив/спецкурс)

### 4. Бонусное задание: Облачная подгрузка фото
* Каждому преподавателю задан адрес в облачном объектном хранилище (`https://storage.yandexcloud.net/edu-platform-lecturers/...`).
* Реализован специализированный компонент `LecturerImage`:
  * Пытается загрузить изображение из облака Yandex Cloud.
  * При недоступности облачной корзины или отсутствии интернета автоматически переключается на локальный резерв (`public/lecturers/...`) без разрыва верстки.
* В шапке сайта и в блоке фильтров расположен **интерактивный переключатель режима**:
  `☁️ Yandex Cloud` / `💻 Local Storage`, позволяющий наглядно проверить оба варианта.

### 5. Расширение функционала платформы
* **Многоуровневая фильтрация и умный поиск**:
  * Живой поиск по именам, дисциплинам и ключевым словам лекций (например, *Python, ДНК, Алгебра, ЕГЭ*).
  * Фильтр по полу: «Все», «Мужчины (5)», «Женщины (5)».
  * Фильтр по ученой степени: «Доктора наук», «Кандидаты наук», «Практикующие специалисты».
  * Фильтр по направлениям наук (10 категорий).
  * Сортировка: по стажу, по минимальной стоимости от дешевых или от дорогих.
* **Модальное окно программы курса (Syllabus Modal)**:
  * Просмотр полной программы со всеми 10 темами по каждой дисциплине выбранного лектора.
* **Интерактивная форма бронирования (BookingModal)**:
  * Выбор статуса заказчика: Физическое лицо или Юридическое лицо (с указанием компании/вуза).
  * Выбор тарифа и формата (онлайн / очный выезд).
  * Валидация полей, интерактивный экран успешного подтверждения бронирования.
* **Интерактивный калькулятор стоимости**:
  * Расчет индивидуального пакета занятий (1, 4, 8, 12, 16 занятий).
  * Автоматический расчет прогрессивной скидки (5%, 10%, 15%, 20%).
  * Мгновенный переход к бронированию рассчитанного курса.
* **Секции "Этапы работы", "Отзывы", "FAQ-аккордеон", "Контакты и заявка на КП"**.
* **Полная адаптивность**: качественное отображение на экранах мобильных телефонов, планшетов и широкоформатных мониторов.

## 🚀 Инструкция по установке и запуску

### Запуск в режиме разработки:
```bash
# 1. Установка зависимостей (только чистый React и Vite)
pnpm install
# или
npm install

# 2. Запуск локального сервера разработки
pnpm dev
# или
npm run dev
```
Сервер запустится по адресу: `http://localhost:3000` (или `http://localhost:5173`).

### Сборка для production:
```bash
pnpm run build
# или
npm run build
```

### Предпросмотр собранного проекта:
```bash
pnpm run preview
# или
npm run preview
```
